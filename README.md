# КАДР / PRICE OPS

Локальный калькулятор и каталог SKU. Единственный источник актуальных тарифов, расчётной стоимости материалов и чернил — [«Прайс КАДР»](https://docs.google.com/spreadsheets/d/1nSzupuFxqx2JImjR7eXQmKTP2uWS6wok9hXCI23-n4k/edit).

`seed.json` — снимок исходных данных для автономной работы приложения, а не отдельный утверждённый прайс. Данные пользователя хранятся в IndexedDB и не синхронизируются с Google Таблицей или между устройствами. Перед предложением цены клиенту сверяйте тариф и себестоимость с основным прайсом; при расхождении действует таблица. Принятые клиентом условия конкретного заказа фиксируются в CRM.

При изменениях схемы локальных данных сначала сохраняйте JSON-экспорт. Не очищайте IndexedDB без отдельной задачи и проверки миграции.
