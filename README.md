# КАДР / PRICE OPS

Локальный PWA-калькулятор прайса, себестоимости и маржи для небольшой студии печати в Батуми.

## Функции

- 66 исходных SKU из действующей Google Таблицы КАДРА.
- Прайс за SKU, в том числе комплект из нескольких изделий.
- Расход бумаги и чернил с округлением до целого листа **по всему заказу**.
- Редактирование SKU, материалов, скидки и стоимости работы.
- Доход, затраты, прибыль и маржа конкретного заказа.
- Локальное IndexedDB-хранилище, JSON-экспорт/импорт, offline-PWA.
- Нет сервера, авторизации, CRM или складского учёта.

## Публикация

GitHub Pages: Settings → Pages → Source: GitHub Actions. Workflow в `.github/workflows/deploy.yml` публикует сайт из корня репозитория.

## Важно

- Первоначальные цены некоторых материалов — **ориентиры**, уточнить по фактическим закупкам.
- Бумага A4 200 г/м² требует проверки совместимости с HP Smart Tank 580.
- Расчёт труда, упаковки, доставки, налогов и брака выполняется вручную в калькуляторе заказа.
- Данные хранятся только на конкретном устройстве: обязательно скачивайте резервные копии JSON.
- Приложение полностью публично доступно по адресу GitHub Pages, но рабочие пользовательские данные не отправляются на GitHub.

## Локальный запуск

Любой статический HTTP-сервер из корня проекта, например `python -m http.server 8080`. Открыть `http://localhost:8080`.
